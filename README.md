# TETRIS
Этот код представляет собой классическую реализацию игры "Тетрис" с использованием библиотеки pygame. Игра включает в себя следующие основные функции:
Описание кода игры "Tetris"
1. Инициализация и настройка игры
- Импортируются необходимые модули: `pygame`, `random`.
- Устанавливаются глобальные параметры:
  - Размер игрового поля: 10x20 блоков.
  - Размеры окна: 950x750 пикселей.
  - Размеры игровой зоны: 300x600 пикселей.
  - Пути к вспомогательным файлам: рекорд, шрифты.
- Определяются формы тетромино (фигур) и их цвета.
2. Класс `Piece`
- Представляет каждую падающую фигуру:
  - Координаты (`x`, `y`).
  - Форма (`shape`).
  - Цвет (`color`).
  - Текущий поворот (`rotation`).
3. Основные функции
- `create_grid(locked_pos)` — создает сетку игрового поля, учитывая уже занятые позиции.
- `convert_shape_format(piece)` — преобразует форму фигуры в список координат на сетке.
- `valid_space(piece, grid)` — проверяет, можно ли разместить фигуру в данной позиции.
- `check_lost(positions)` — определяет, достигли ли фигуры верха поля (конец игры).
- `get_shape()` — случайным образом выбирает следующую фигуру.
- `clear_rows(grid, locked)` — удаляет полностью заполненные строки и сдвигает верхние вниз. Возвращает количество очищенных строк.
- `draw_text_middle(text, size, color, surface)` — отображает текст по центру экрана (для меню и сообщений).
- `draw_grid(surface)` — рисует сетку игрового поля.
- `draw_next_shape(shape, surface)` — показывает следующую фигуру в боковой панели.
- `draw_window(surface, grid, score, last_score)` — отрисовывает весь интерфейс, включая фон, игровое поле, счет, рекорд и сетку.
- `update_score(new_score)` — обновляет рекорд в файле, если текущий счет выше.
- `get_max_score()` — считывает рекорд из файла.
4. Игровой процесс
- `main(window)` — основной игровой цикл:
  - Управление фигурами (движение, поворот, ускорение).
  - Проверка на столкновения и очистку строк.
  - Подсчет очков и обновление рекорда.
  - Отрисовка графики.
  - При поражении возвращает игрока в главное меню.
- `main_menu(window)` — стартовый экран, ожидающий нажатия клавиши для начала игры.
5. Запуск игры
- Инициализируется окно `pygame`.
- Устанавливается заголовок "Tetris".
- Запускается главное меню (`main_menu`).
  
Ключевые особенности:
1. Динамическая сложность — скорость падения фигур увеличивается каждые 5 секунд, вплоть до минимального значения 0.15 секунды.

2. Система рекордов — рекорд сохраняется в файл `highscore.txt` и отображается во время игры.

3. Визуализация:
   - Сетка игрового поля.
   - Предпросмотр следующей фигуры.
   - Фоновое изображение .

4. Управление:
   - Стрелки влево/вправо — движение фигуры.
   - Стрелка вверх — поворот фигуры.
   - Стрелка вниз — ускоренное падение.
